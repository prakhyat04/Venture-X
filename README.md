# VentureX — Premium eSports Gaming Platform

**VentureX** is a next-generation competitive eSports platform connecting players, casters, communities, and fans across premier gaming titles (VALORANT, Counter-Strike 2, BGMI, Apex Legends, and more).

## 🌟 Key Features

- **🏆 Tournaments & Brackets**: Interactive bracket visualization, registration wizard, prize pools, and schedule tracking.
- **🔴 Live Broadcast Theater**: Real-time stream player, responsive chat panel, live viewer counts, and multi-channel navigation.
- **🎙️ Casters & Analyst Desks**: Verified caster directory, bio profiles, voice stats, social links, and broadcast schedules.
- **🎮 Game Communities & Guilds**: Verified communities, scrims, discussions, and member management.
- **⚡ Pro Player Leaderboards**: Global rankings, K/D ratios, seasonal win rates, and badges.
- **📹 Video Vault & Highlights**: High-definition match recaps, clutch clips, and interactive comments.
- **📡 Stream Setup Wizard**: Complete 7-step streamer setup desk with RTMP ingest credentials and instant go-live capability.
- **✨ Aesthetics**: Royal Gold Dark competitive theme, dynamic particle effects, fluid animations, and mobile-responsive layout.
